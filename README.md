# 🎨 Vue Learning Project

Proyecto de aprendizaje y práctica con Vue.js 3, incluyendo componentes reutilizables y patrones modernos de desarrollo.

## 📋 Descripción

Este repositorio contiene mi exploración práctica de Vue.js, implementando diversos componentes y funcionalidades para dominar el framework. El proyecto sirve como laboratorio de pruebas para patrones de diseño, composables, y características avanzadas de Vue.

## ✨ Características

- **Vue 3** con Composition API
- Sistema de componentes reutilizables
- Gestión de estado reactivo
- Integración de Vue Router
- Prácticas de componentes funcionales

## 🛠️ Tecnologías

- **Framework:** Vue.js 3
- **Lenguaje:** JavaScript (ES6+)
- **Herramientas:** Vite, Vue Router

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/maniacdi/vue-project.git

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev
```

## 📂 Estructura

```
vue-project/
├── src/
│   ├── components/     # Componentes reutilizables
│   ├── views/          # Vistas de la aplicación
│   ├── router/         # Configuración de rutas
│   └── App.vue         # Componente raíz
└── public/             # Assets estáticos
```

## 🎯 Conceptos Implementados

- ✅ Componentes con props y eventos
- ✅ Composables personalizados
- ✅ Directivas de Vue
- ✅ Ciclo de vida de componentes
- ✅ Reactividad con `ref` y `reactive`
- ✅ Navegación con Vue Router
